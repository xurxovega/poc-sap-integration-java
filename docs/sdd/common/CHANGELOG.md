# Changelog — shared kernel common

> Índice cronológico de los cambios de las capacidades de `common`. Una línea por cambio;
> el detalle vive en la sección **Cambios** del spec de cada feature, y la
> información ampliada (quién lo pidió, cuándo, estado) en el registro MySQL
> `sdd_registry` — ver [`../README.md`](../README.md) §8.

Wire Kafka 3.x, cero cambios en la app cliente (renombrado cosmético `KAFKA_BOOTSTRAP` → `MESSAGING_BOOTSTRAP`); Operator + CRD `cluster.redpanda.com/v1alpha2` `kind: Redpanda`, manifests Kustomize puros, un cluster por clúster K8s, RF=3 en test/prod / RF=1 en local, Tiered Storage desactivado (OPS-011 propuesto). D-16 cerrado por [ADR-0014](../architecture/adr/0014-redpanda-como-broker-de-mensajeria.md) y revisión de [ADR-0011](../architecture/adr/0011-concurrencia-entre-instancias-fencing-sin-lease.md) (consumer group por clúster).
