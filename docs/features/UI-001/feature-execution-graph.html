Decisiones y evidencias

Lectura directa Mongo+ES, no APIs REST

Tres herramientas a una: el operario deja de abrir Mongo, ES y Grafana por separado. DashboardIsolationTest (3 reglas ArchUnit) garantiza que la frontera entre bounded contexts no se cruce.

PiiMasker promovido a common.security

El panel y la API REST del customer-app enmascaran con la misma clase. Fachada @Deprecated en customer.bootstrap.web para no romper los tests legacy.

Cardinalidad acotada en KPIs

Gauges business_kpi_mttr_seconds{window='7d'} y business_kpi_recovery_p95_seconds{cycle='last'}: cardinalidad ≤ 2 series. Sin etiqueta por entityId: un cliente es un punto, no una serie.

Thymeleaf+HTMX+Alpine.js

Sin SPA, sin build JS, sin servidor de estáticos. Render server-side; HTMX hace el patch sobre el mismo DOM. UI-6 (React+Vite) queda descartado.

ACK como F-9 promoted

POST /customers/alerts/{id}/ack con sap-write, persiste ackedAt/ackedBy en Mongo. Cuatro índices en init.js: alert_id_uk, entity_acked_idx, acked_ttl, opened_ttl.

Métricas Prometheus propias (F-12)

El dashboard emite series con application='dashboard-customer' y los gauges business_kpi_*. Job KpiJob corre @Scheduled dentro del módulo.
